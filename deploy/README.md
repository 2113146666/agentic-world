# 腾讯云轻量部署（网页终端）

本机 SSH 不通时，全程用控制台网页「登录」。不要在云上跑 `npm run dev`，不要把 8000 开到公网。

## 控制台

防火墙放行 **TCP 80**（22 已有即可）。不要放行 8000。

实例 → **登录**（网页终端）。用户是 `ubuntu`。

## 服务器命令

见对话里按步粘贴的四段。nginx / systemd 用 heredoc 写入，因 `deploy/` 可能还不在 GitHub。

构建前端时必须 `VITE_API_BASE_URL=` 为空，浏览器走同源 `/api`。

浏览器打开 `http://公网IP/`。
